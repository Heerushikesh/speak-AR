# Speak AR - AI and AR Powered Gamified Learning App Website

## 1. Project Overview

**Project Name:** Speak AR Website
**Project Type:** Multi-page Marketing Website with Interactive Elements
**Core Functionality:** Showcase an AI and AR powered gamified language learning app with immersive animations and multiple pages
**Target Users:** Language learners, parents, educators, tech-savvy individuals interested in innovative learning methods

## 2. UI/UX Specification

### Layout Structure

**Pages:**
1. **Home (index.html)** - Hero section, features overview, animated AR showcase
2. **Features (features.html)** - Detailed feature breakdown with animations
3. **How It Works (how-it-works.html)** - Step-by-step process visualization
4. **Demo (demo.html)** - Interactive AR experience simulation
5. **Contact (contact.html)** - Contact form with animated elements

**Page Sections:**
- Fixed navigation bar (glassmorphism effect)
- Hero sections with animated backgrounds
- Content sections with scroll-triggered animations
- Footer with social links and navigation

**Responsive Breakpoints:**
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

### Visual Design

**Color Palette:**
- Primary: #0A0E27 (Deep Space Blue)
- Secondary: #1A1F4E (Midnight Purple)
- Accent 1: #00F5D4 (Cyber Cyan)
- Accent 2: #FF6B9D (Neon Pink)
- Accent 3: #7B2FFF (Electric Purple)
- Accent 4: #FFE66D (Golden Yellow)
- Text Primary: #FFFFFF
- Text Secondary: #B8B8D1

**Typography:**
- Headings: "Orbitron" (Google Fonts) - futuristic, tech feel
- Body: "Exo 2" (Google Fonts) - clean, modern readability
- Accent: "Press Start 2P" (Google Fonts) - for gamified elements

**Font Sizes:**
- H1: 4rem (desktop), 2.5rem (mobile)
- H2: 3rem (desktop), 2rem (mobile)
- H3: 2rem (desktop), 1.5rem (mobile)
- Body: 1.1rem
- Small: 0.9rem

**Spacing System:**
- Section padding: 100px vertical (desktop), 60px (mobile)
- Container max-width: 1200px
- Grid gap: 30px
- Card padding: 40px

**Visual Effects:**
- Glassmorphism cards with backdrop-blur
- Glowing neon borders on hover
- Particle background animations
- Floating 3D elements
- Gradient overlays
- Holographic effects

### Components

**Navigation:**
- Logo with glow animation
- Menu items with underline slide animation
- Mobile hamburger menu with morphing animation
- Active page indicator

**Buttons:**
- Primary: Gradient background with pulse animation
- Secondary: Transparent with neon border
- Hover: Scale up + glow intensifies
- Click: Ripple effect

**Cards:**
- Feature cards with tilt effect on hover
- 3D flip animation on interaction
- Holographic shine effect
- Floating animation

**Animations:**
- Page load: Staggered fade-in from bottom
- Scroll: Elements slide in from sides
- Hover: Multiple layered animations
- Background: Floating particles, gradient shifts
- Loading: Holographic spinner
